# 衡学 Study Balance

一个给自己用的学习管理小应用：今日总览、任务清单、智能日历、负载分析、专注模式（白噪音 + 专注小花园）、习惯打卡、考试倒计时。

- **电脑版**：双击 `启动衡学.bat`（需要 Node.js），数据存在本机 `data.json`，手机在同一 Wi-Fi 下也能访问。详见 `使用说明.md`。
- **网页版**：本仓库同时是一个纯静态网页（`public/` 目录），数据保存在各设备浏览器里，可用「导出备份 / 导入备份」在设备间搬家。

界面为奶油底色 + 黑描边卡片的 soft-brutalism 风格，纯原生 HTML/CSS/JS 实现，无任何第三方依赖。
